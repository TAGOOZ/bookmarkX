# Full RTL + Thmanyah Font

Full RTL layout support — UI mirrors when Arabic content is detected (sidebar moves right, text aligns right, navigation flips). Mixed Arabic/English text handled via Unicode Bidirectional Algorithm. Thmanyah font family covers both Arabic and Latin characters — one font for both languages, ensuring visual consistency. Serif Display for headings, Serif Text for body, Sans for UI. Free for commercial use.
