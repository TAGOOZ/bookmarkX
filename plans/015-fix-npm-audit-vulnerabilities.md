**Out of scope**:

## Steps

### Step 1: Run audit to see current state

```bash
pnpm audit 2>&1
```

### Step 2: Update direct dependencies where possible

Try `pnpm update` to pull in patched versions:

```bash
pnpm update
```

Then re-run audit to see if any vulnerabilities were resolved.

### Step 3: Check for remaining vulnerabilities

```bash
pnpm audit 2>&1
```

If critical/high vulnerabilities remain in transitive deps (via electron-forge), note them but do not force-resolve — those require electron-forge to update their dependencies.

### Step 4: Run full verification

**Verify**: `pnpm lint && pnpm test` → exit 0, all tests pass
